# 成分唛工作台功能总览（v1.3）

本项目是 Windows 桌面应用，用于根据服装成分、面料颜色和参考照片，批量生成无尺码的成分唛图片，并完成审核、重新生成和导出。

主要流程：**配置 API → 选择或录入成分 → 选择颜色和参考图 → 批量加入队列 → 生成及自动重试 → 人工审核 → 导出批准的图片**。

## 1. 成分库与 Excel 导入

- 内置 119 条有效成分预设，保留原中文描述和来源信息。
- 支持中英文搜索、多选、选择当前可见条目和清空选择。
- 可将选中的成分带入自定义编辑器修改。
- 导入 `.xlsx`、`.xlsm` 文件，读取工作表 C 列；多工作表文件可选择工作表。
- 导入有效成分后替换当前成分库；无效行被跳过，并提供行号、原文和原因。
- 可查看待确认成分，并生成本地导入错误报告。

## 2. 自定义成分与文本解析

- 添加或删除纤维行，选择或输入英文纤维名称，设置百分比。
- 成分名称需能被现有别名字典识别；图像生成接口最多接受 12 项成分。
- 支持百分比小数，检查总比例是否符合 100% 要求。
- 支持粘贴中英文成分文本并解析，例如 `棉65%聚酯纤维35%`。
- 可调用文字模型解释和规范化成分文本；输出仍会经过成分和比例校验。
- 创建前显示预期标签文字，以及“成分数 × 颜色数 = 图片数”。
- 可将全部有效成分与 12 种文档颜色一次组合入队；确认框显示任务数和最多计费尝试次数，确认后仍需手动点击开始。

## 3. 面料颜色与参考图

- 内置 12 种颜色：浅蓝、宝蓝、米白、藏青、湖蓝、黑色、绿色、酒红、白色、灰色、红色、橙色。
- 支持颜色多选、全选和清空。
- 内置对应面料或颜色参考照片。
- 支持上传 PNG、JPEG、WebP 自定义面料参考图，也可恢复默认参考。
- 可以替换成分唛版式参考照片，或恢复原始照片。
- 自定义面料图用于辅助面料外观；所选颜色仍然生效，不会自动新增颜色选项。

## 4. AI 图片生成

- 每个“成分 × 颜色”组合生成一个独立任务。
- 通过参考图向模型提出保持标签位置、构图、面料纹理和缝线的要求。
- 标签内容使用英文成分及比例，并包含 `Made in China`。
- 提示词要求去除尺码，保留米白标签和黑色文字，调整周围面料颜色。
- 支持单一成分和混纺多行文字。
- 生成结果保存为 PNG；文件名包含成分、颜色和短任务号，图片解码和文件写入完成后进入待审核状态。

上述外观和文字是模型生成要求，并非程序自动校验后的保证。

## 5. 队列、并发与自动重试

- 支持开始、暂停、继续和取消等待中的任务。
- 支持设置 1–4 个并发任务；生成请求启动至少间隔 10 秒。
- 对 HTTP 408、429、5xx、连接中断和超时等临时错误，在同一任务上自动重试。
- 每次临时失败后至少等待 10 秒；首次请求加重试共最多 3 次。
- 前两次临时失败显示 Retrying；第三次仍失败显示 Failed，可重新生成，其他任务继续处理。
- 密钥、参数、证书等配置错误和未识别异常直接失败并暂停队列。
- 保存每条任务的尝试次数、每次尝试时间和错误信息。
- 暂停时停止发出新请求；已发出的请求继续完成。
- 取消等待任务也会取消待重试任务；已发出请求失败后不再自动重试。
- 重启不会自动启动队列；待重试任务保留次数，原来正在请求的任务标记为中断。

| 状态 | 含义 |
| --- | --- |
| Queued | 等待开始 |
| Running | 正在执行一次生成请求 |
| Retrying | 临时失败，等待下一次自动尝试 |
| Review | 已生成，等待人工审核 |
| Approved | 已批准，可导出 |
| Failed | 尝试耗尽，或遇到不自动重试的错误 |
| Cancelled | 已取消 |
| Interrupted | 上次关闭时尚在生成，需检查后手动重生成 |

10 秒是请求间隔或重试等待时间，不是图片生成耗时；并发繁忙时实际等待可能更长。

## 6. 图片审核与单张重新生成

- 在任务列表选择图片，查看预览、预期文字、颜色、状态、模型和错误。
- 可以打开原尺寸图片。
- 人工核对成分、文字、颜色和缝线后批准图片。
- 可填写修改意见并重新生成；新版本与原任务关联，原记录和图片保留。
- 可一次为符合条件的失败或中断任务创建重试版本，避免重复加入已有后续版本。
- 新生成的版本获得新的 3 次尝试额度。

## 7. 批量选择与批量重新生成（v1.2）

- Ctrl-click 选择多个不连续任务，Shift-click 选择连续范围。
- 提供 Select all / 全选、Clear / 清空和选中数量提示。
- 自动刷新时保留已选任务、当前预览、滚动位置，以及正常行顺序下的 Ctrl/Shift 选择行为。
- 点击 Regenerate selected / 批量重生成，为每条符合条件的任务创建新版本。
- 反馈框有内容时统一应用；留空时分别沿用原任务备注。
- 跳过排队、运行和自动重试中的任务；若原任务已有直接的新版本尚未完成，也会跳过。
- 原图片、批准状态和历史记录保留，提示栏说明新增及跳过数量。
- 队列运行中会处理新版本；队列暂停时需要点击开始。

批量操作针对实际选中的记录，不会自动将同一颜色的所有历史版本合并为一条。

## 8. 图片导出

- 一次导出所有已批准任务的图片；任意一张已批准图片缺失时，会阻止本次导出并提示重新生成。
- 导出 PNG 图片和 `manifest.json` 清单。
- 图片文件名包含成分、颜色和任务标识。
- 清单包含图片文件名、成分、颜色、预期文字、模型和批准时间。
- 已批准的历史版本也会包含在导出中；重新生成不会自动撤销旧版本的批准。
- 每次导出创建独立文件夹。
- 导出内容不包含 API 密钥。

## 9. API、模型和参数设置

- 支持 OpenAI、兼容 OpenAI 的图像编辑接口和 Google Gemini 接入方式。
- 配置 API 地址和密钥，测试连接并获取账户可用模型列表。
- 图像模型和文字模型分开选择，也可手动填写模型 ID。
- 支持设置图像质量、像素尺寸和并发数；可用参数取决于服务商。
- Gemini 模式下不开放界面中的 OpenAI 式质量和尺寸选择。
- 可以保存设置并打开本地数据目录。

获取到模型列表不代表其中所有模型都能生成图片，图像模型仍需支持相应参考图请求。

## 10. 本地保存与桌面发布

- Windows 10/11 64 位便携程序，保留 `_internal` 文件夹即可运行，无需另装 Python。
- 设置、任务、参考图和生成图片保存在当前 Windows 用户的本地数据目录。
- 默认目录：`%LOCALAPPDATA%\FabricLabelStudio`。
- API 密钥使用 Windows DPAPI 加密保存；设置和任务采用临时文件替换的方式写入，减少不完整写入。
- 升级同一用户下的程序后可继续读取原数据。
- 源码附有自动化测试、界面截图脚本、Windows 打包脚本和发布包启动验证脚本。

## 当前没有的功能

- 没有 OCR 自动核对成分文字、自动判定颜色或图片质量、自动批准。
- 没有批量批准按钮；当前批准操作针对正在预览的一张图片。
- 没有自由新增颜色、自由编辑标签所有文案或画布排版的界面。
- 没有服务商故障时自动切换模型或 API 的功能。
- 没有云端同步、多人协作、任务账号权限管理或费用统计面板。
- 没有直接导出 PDF、Excel 清单、印刷排版文件或调用打印机的功能。

AI 请求和重试由服务商计费；本地重试机制无法保证服务商不再返回 502 等错误。

## 主要源码位置

| 文件 | 职责 |
| --- | --- |
| `studio/app.py` | 桌面界面、任务队列、重试、审核、批量操作和导出 |
| `studio/domain.py` | 成分解析、校验、文字格式化及 Excel 导入 |
| `studio/providers.py` | API 请求、提示词、图像处理、模型发现和错误分类 |
| `studio/storage.py` | 本地数据保存与 API 密钥加密 |
| `studio/theme.py` | 界面样式 |
| `assets/` | 成分目录、颜色参考图和版式示例 |
| `tests/`、`scripts/` | 回归测试、辅助验证和打包 |

本清单基于当前 v1.3 源码整理，未将生成目标写成自动校验能力，也未将后续可扩展功能列为已实现。
