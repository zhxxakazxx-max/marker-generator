# 成分唛工作台 v1.3 使用说明

## 打开软件

适用 Windows 10/11 64 位。将整个 ZIP 解压到任意文件夹，双击 `FabricLabelStudio.exe`。请保留旁边的 `_internal` 文件夹，无需安装 Python。

## 配置模型

点击左侧 **API & models**。选择 OpenAI、兼容 OpenAI 的服务或 Google Gemini，填写 API 地址和密钥。点击 **测试并获取模型**，选择图像模型、文字模型，再点击 **保存设置**。也可以直接输入模型 ID。图像模型必须支持参考图编辑；文字模型仅用于“AI interpret text”。API 费用由服务商收取。

## 批量生成

1. 在 **创建** 页，从成分库多选所需成分。也可导入 Excel，读取 C 列。
2. 在 **自定义** 页可选成分、填写比例，或粘贴 `棉65%聚酯纤维35%`。总比例需为 100%。
3. 多选面料颜色，默认有工作簿中的 12 种。也可上传自定义面料参考图。
4. 点击 **加入队列**。成分数 × 颜色数 = 图片数。若要处理文档中的全部组合，导入 Excel 后点击 **Queue all document combinations / 全部组合入队**；确认框会显示准确任务数和最多尝试次数。确认只会入队，不会启动 API。
5. 在 **审核** 页点击 **开始**，软件按设置并发生成，最多同时 4 个任务。
6. 逐个查看图片，核对百分比、英文成分、`Made in China`、颜色及缝线。图片中不应有尺码。
7. 满意点击 **批准**；否则填写修改意见并点击 **重生成**，旧版本保留。需要多张重生成时，按下方“批量重新生成”操作。若队列暂停，再点击开始。
8. 点击 **Export approved**，选择保存位置，导出批准的 PNG 和成分清单。

## 批量重新生成

1. 在 **审核 / Review** 页按住 **Ctrl** 点击多个任务行；按住 **Shift** 点击可选中连续范围。也可点击 **Select all / 全选**，用 **Clear / 清空** 取消全部选择。
2. 需要统一修改时，在原有反馈输入框填写共同要求。输入框非空时，所选任务的新版本都使用这份要求；留空则分别保留各任务原有的修改意见。
3. 点击 **Regenerate selected / 批量重生成**。提示栏会显示已加入队列和已跳过的数量。刷新列表或执行批量操作后，原有选择仍会保留。
4. 队列暂停时点击 **Start / 开始**；正在运行的队列会继续处理新加入的版本。

可重新生成的状态为 **Failed、Review、Approved、Cancelled、Interrupted**。**Queued、Running、Retrying** 会跳过；若某条旧任务已有直接生成的新版本处于这三种待完成状态，也会跳过，避免重复点击时再次排队。原任务的图片、状态和记录保留，每条符合条件的任务各新增一个排队版本，已用尝试次数从 0 开始，最多尝试 3 次，请求启动间隔仍至少为 10 秒。完整规则与升级说明见 [v1.2 批量重新生成](BATCH_REGENERATE.zh-CN.md)。

## 数据与生成说明

软件内置 119 条有效成分和 12 张原始颜色/面料参考图。C48、C107 中 `PU皮革` 未提供比例，列入“待确认成分”，请确认后手工输入。

AI 生成无法保证每次文字、构图和色彩都完全一致，因此每张图需要预览审核。示例图只是无尺码版式示例。未填写 API Key 时可以浏览和编排任务，不能调用付费模型生成。

密钥使用 Windows DPAPI 加密，数据保存在 `%LOCALAPPDATA%\FabricLabelStudio`。暂停会停止启动新任务，正在调用的任务会继续完成。运行中请等待任务结束再关闭软件。

v1.3 沿用现有队列规则：默认每隔至少 10 秒启动一个生成请求。HTTP 502 等临时错误在同一任务上自动重试，失败后至少等待 10 秒，首次加重试共最多 3 次。前两次显示 Retrying；第 3 次失败才显示 Failed 并启用 Regenerate。配置错误会直接暂停。“重试失败任务”会创建新版本，旧结果保留。重试可能产生新的费用；暂停时不会启动重试，再点击开始会继续且保留次数。生成和导出的文件名采用“成分__颜色__短任务号.png”。
